Project Overview

Pawsome Pet Co. runs a monthly Birthday Club campaign for customers whose pets have birthdays during the current month. This campaign combines a personalized birthday message, customer-specific discount, loyalty-tier messaging and two pet-relevant gift recommendations. The campaign is designed as an AMPscript-heavy SFMC email rather than a static HTML creative.

Objective

Build a Monthly Birthday Club email that feels personal and brand-led while demonstrating practical AMPscript skills. The supplied Birthday Club DE acts as the send audience, while lookup Data Extensions provide reusable pet personality content and gift recommendations.

Campaign Flow

Birthday Club DE
       ↓
Subscriber + Pet Attributes
       ↓
AMPscript
       ├── First Name fallback
       ├── Pet Personality lookup
       ├── Loyalty-tier subject line
       ├── Gift recommendation lookup
       ├── Discount calculation
       └── Pet-type banner selection
       ↓
Personalized MJML / HTML Email
       ↓
September Birthday Club Send

The provided send audience already contains customers with September pet birthdays, so no SQL audience-selection step is required for this campaign. AMPscript performs the runtime content assembly and personalization inside the email.

AMPscript

AMPscript is the primary orchestration layer. It reads the sendable subscriber attributes, retrieves reusable content from the lookup Data Extensions, builds the personalized subject line, calculates recommendation prices after the birthday discount and selects the appropriate hero image. 

%%[
var @subscriberKey, @firstName, @emailAddress, @petName, @petType, @discountPercent, @loyaltyTier

SET @subscriberKey = AttributeValue("SubscriberKey")
SET @firstName = AttributeValue("FirstName")
SET @emailAddress = AttributeValue("EmailAddress")
SET @petName = AttributeValue("PetName")
SET @petType = AttributeValue("PetType")
SET @discountPercent = AttributeValue("DiscountPercent")
SET @loyaltyTier = AttributeValue("LoyaltyTier")
SET @date = SystemDateToLocalDate(Now(1))
SET @offerMonth = FormatDate(@date, 'MMMM')
SET @offerValidity = FormatDate(@date, 'Y')

/*Validate firstName*/
IF EMPTY(@firstName) THEN
	SET @firstName = 'there'
ENDIF

/*Content(personality) based on pet type*/
SET @petPersonalityRows = LookupRows('Pet Personality', 'PetType', @petType)
IF rowCount(@petPersonalityRows) > 0 THEN
	VAR @row, @birthdayHeadline, @birthdayPersonality, @petDescription
	SET @row = Row(@petPersonalityRows, 1)
	SET @birthdayHeadline = Field(@row, 'BirthdayHeadline')
	SET @birthdayPersonality = Field(@row, 'BirthdayPersonality')
	SET @petDescription = Field(@row, 'PetDescription')
	SET @petEmoji = Field(@row, 'petEmoji')
ENDIF

/*Dynamic subjectline based on loyalty tier*/
IF @loyaltyTier == 'Platinum' THEN
	SET @subjectline = Concat('A VIP birthday treat, just for ', @petName, ' ', @petEmoji)
ELSEIF @loyaltyTier == 'Gold' THEN
	SET @subjectline = Concat('Celebrate ', @petName,' with a birthday treat from us ', @petEmoji)
ELSEIF @loyaltyTier == 'Silver' THEN
	SET @subjectline = Concat("Extra cuddles. Extra treats. It's ", @petName, "'s birthday! ", @petEmoji)
ELSE
	SET @subjectline = Concat("It's paw-ty time ", @petName, "! Your birthday treat is waiting ", @petEmoji)
ENDIF

/*Get 2 gift recommendations*/
SET @giftIdeasRows = LookupOrderedRows('Gift Ideas', 2, 'Price DESC', 'PetType', @petType)
SET @giftIdeasCount = rowCount(@giftIdeasRows)
SET @giftRow1 = Row(@giftIdeasRows, 1)
SET @giftName1 = Field(@giftRow1, 'GiftName')
SET @giftPrice1 = Field(@giftRow1, 'Price')
SET @formatGiftPrice1 = FormatNumber(@giftPrice1, "C")
SET @finalPrice1 = FormatNumber(Subtract(@giftPrice1, Multiply(@giftPrice1, Divide(@discountPercent, 100))), "C")
SET @giftDescription1 = Field(@giftRow1, 'Description')
SET @shopURL1 = Field(@giftRow1, 'ShopURL')
SET @imageURL1 = Field(@giftRow1, 'ImageURL')

IF @giftIdeasCount == 2 THEN
	SET @giftRow2 = Row(@giftIdeasRows, 2)
	SET @giftName2 = Field(@giftRow2, 'GiftName')
	SET @giftPrice2 = Field(@giftRow2, 'Price')
	SET @formatGiftPrice2 = FormatNumber(@giftPrice2, "C")
	SET @finalPrice2 = FormatNumber(Subtract(@giftPrice2, Multiply(@giftPrice2, Divide(@discountPercent, 100))), "C")
	SET @giftDescription2 = Field(@giftRow2, 'Description')
	SET @shopURL2 = Field(@giftRow2, 'ShopURL')
	SET @imageURL2 = Field(@giftRow2, 'ImageURL')
ELSE
	SET @giftIdeasRowsAll = LookupOrderedRows('Gift Ideas', 1, 'Price DESC', 'PetType', 'All')
	SET @giftRow2 = Row(@giftIdeasRowsAll, 1)
	SET @giftName2 = Field(@giftRow2, 'GiftName')
	SET @giftPrice2 = Field(@giftRow2, 'Price')
	SET @formatGiftPrice2 = FormatNumber(@giftPrice2, "C")
	SET @finalPrice2 = FormatNumber(Subtract(@giftPrice2, Multiply(@giftPrice2, Divide(@discountPercent, 100))), "C")
	SET @giftDescription2 = Field(@giftRow2, 'Description')
	SET @shopURL2 = Field(@giftRow2, 'ShopURL')
	SET @imageURL2 = Field(@giftRow2, 'ImageURL')
ENDIF

/*Dynamic banner based on pet type*/
IF @petType == 'Dog' THEN
	SET @banner = 'https://as1.ftcdn.net/v2/jpg/03/22/78/92/1000_F_322789275_pRYGzHcwPOBFiSD34xXIMILVMGxfqJBV.jpg'
ELSE
	SET @banner = 'https://images.ampscriptacademy.com.au/uploads/hero-gemini-removebg-preview.png'
ENDIF
]%%

Dynamic Content & Personalization

Pet Personalization PetName is used throughout the birthday experience and CTA copy.
Optional First Name FirstName is checked and falls back to “there” when the source value is empty.
Pet Personality Headline, personality copy and emoji are retrieved from the Pet Personality DE by PetType.
Loyalty-Tier Subject Platinum, Gold, Silver and Bronze/default customers receive different subject-line treatments.
Personalized Offer Discount percentage and unique DiscountCode are read directly from the send audience.
September Validity The offer is presented as valid throughout the campaign month rather than calculating a daily expiry date.
Pet-Based Recommendations Up to two gift records are selected using PetType and ordered by price.
Recommendation Fallback If only one pet-specific gift exists, an “All” gift fills the second recommendation slot.
Dynamic Pricing Recommendation prices show the original price and the customer-specific discounted price.
Dynamic Hero Banner The banner image changes based on the subscriber’s PetType.

Implementation Notes

The campaign intentionally keeps the creative structure simple: one birthday hero/message area, one personalized offer and two recommendation sections with alternating layouts. This keeps the email visually engaging while leaving AMPscript as the primary technical focus.

The Gift Ideas lookup uses two pet-specific records when available. If only one exists, the first recommendation remains pet-specific and the second is populated from a generic “All” record. The email therefore maintains its two-product layout without hard-coding product content into the HTML.

Key Features

AMPscript-First Architecture Business and personalization logic is handled in AMPscript rather than hard-coded into the creative.
Multiple DE Lookups Subscriber data drives lookups into Pet Personality and Gift Ideas.
Conditional Logic First-name fallback, loyalty-tier subject logic and gift fallback logic are handled at send time.
Dynamic Product Content Gift name, description, original price, discounted price, image and URL are data-driven.
Reusable Content Model Pet personality and gift content live in lookup DEs instead of being duplicated in the email.
Responsive Email Email structure is developed in MJML and compiled to responsive HTML.
