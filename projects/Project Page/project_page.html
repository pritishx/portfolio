Description

A technical consulting company allows customers to schedule consultation sessions for different technologies.

The reminder email is sent one day before the appointment and dynamically displays the customer's name, appointment details, technology, session duration and preparation instructions.

A customer can have multiple appointments over time, but only one session can be booked per day.

SQL

The SQL query selects tomorrow's scheduled appointments before the email send. 

SELECT
    AppointmentID,
    SubscriberKey,
    MeetingDate,
    TechStackID,
    SessionDuration,
    Status
FROM Appointments
WHERE CAST(MeetingDate AS DATE)
      = CAST(DATEADD(DAY, 1, GETDATE()) AS DATE)
AND Status = 'Scheduled'

AMPscript

AMPscript retrieves the customer, appointment and technology information and prepares the dynamic content used in the email. 

set @subscriberKey = AttributeValue('SubscriberKey')
set @firstName = ProperCase(AttributeValue('FirstName'))
set @email = AttributeValue('Email')

set @appointmentRows =
    LookupRows(
        'Appointments',
        'SubscriberKey',
        @subscriberKey
    )

set @techRows =
    LookupRows(
        'Technology',
        'TechStackID',
        @techStackId
    )

Dynamic Session Message

The preparation message changes depending on the technology selected for the appointment. 

if @techStackId == "SFMC" then

    set @sessionMessage =
    "Please have your Marketing Cloud requirements
     and current email or automation examples ready."

elseif @techStackId == "SFDC" then

    set @sessionMessage =
    "Please have your Salesforce CRM requirements
     and current business process details ready."

elseif @techStackId == "MULESOFT" then

    set @sessionMessage =
    "Please have your API documentation and
     integration requirements available."

endif
