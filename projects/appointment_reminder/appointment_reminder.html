Description

A technical consulting company allows customers to schedule consultation sessions for different technologies.

The reminder email is sent one day before the appointment and dynamically displays the customer's name, appointment details, technology, session duration and preparation instructions.

A customer can have multiple appointments over time, but only one session can be booked per day.

SQL

The SQL query selects tomorrow's scheduled appointments before the email send. 

SELECT
    AppointmentID,
    SubscriberKey,
    MeetingDate,
    TechStackID,
    SessionDuration,
    Status
FROM Appointments
WHERE CAST(MeetingDate AS DATE)
      = CAST(DATEADD(DAY, 1, GETDATE()) AS DATE)
AND Status = 'Scheduled'

AMPscript

AMPscript retrieves the customer, appointment and technology information and prepares the dynamic content used in the email. 

set @subscriberKey = AttributeValue('SubscriberKey')
set @firstName = ProperCase(AttributeValue('FirstName'))
set @email = AttributeValue('Email')

/*Appointment DE*/
set @appointmentRows = LookupRows('Appointments', 'SubscriberKey', @subscriberKey)

if(RowCount(@appointmentRows) > 0) then
  set @appointmentRow = Row(@appointmentRows, 1)
  set @meetingDate = Field(@appointmentRow, 'MeetingDate')
  set @techStackId = Field(@appointmentRow, 'TechStackID')
  set @appointmentId = Field(@appointmentRow, 'AppointmentID')
  set @sessionDuration = Field(@appointmentRow, 'SessionDuration')
endif

/*Format appointment date*/
if(not empty(@meetingDate)) then
  set @formattedMeetingDate = FormatDate(@meetingDate, "MMMM dd, yyyy hh:mm tt")
endif

Dynamic Session Message

The preparation message changes depending on the technology selected for the appointment. 

/*Session preparation message*/
if @techStackId == "SFMC" then
  set @sessionMessage = "Please have your Marketing Cloud requirements and current email or automation examples ready."
elseif @techStackId == "SFDC" then
  set @sessionMessage = "Please have your Salesforce CRM requirements and current business process details ready."
elseif @techStackId == "MULESOFT" then
  set @sessionMessage = "Please have your API documentation and integration requirements available."
else
  set @sessionMessage = "Please have your technical requirements ready for discussion."
endif
